# iMotorCom

**iMotorCom** is a peer-to-peer Bluetooth voice chat app for iOS (iOS 5+), designed specifically for motorcycle riders and their passengers. With automatic connection and no pairing required, this app allows for seamless, hands-free communication while on the move.

---

## Why iMotorCom?

Do you ride with a passenger and wish you could chat comfortably without shouting or using hand signals?  
**iMotorCom** lets you:

- Stay connected while riding — even through helmets and heavy wind.
- Avoid pairing steps — just open the app and start talking.
- Use it anywhere — no need for cellular coverage, data plans, or Wi-Fi.
- Multitask with ease — listen to music while staying connected with your passenger.

---

## Key Features

- Real-time Bluetooth voice communication (no internet needed)  
- Instant automatic connection (no pairing required)  
- Optimized for rider-to-passenger chat  
- Best used with noise-cancelling headphones  
- Background audio and headset button support (press the middle button to resume music)

---

## Getting Started

1. Install the app on two or more iOS devices (iOS 5+).
2. Launch **iMotorCom** on each device.
3. The devices will auto-connect using Bluetooth.
4. Start talking — it’s that simple.

Tip: For best results, use noise-cancelling earphones or helmet-integrated audio systems.

---

## Privacy and Connectivity

- All communication happens locally via Bluetooth.
- No internet connection or server required.
- Fully private, with no airtime charges, data usage, or roaming fees.
